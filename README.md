# Карта Дерри

Реконструкция географии вымышленного города Дерри из романа Стивена Кинга «Оно» — только по тексту романа, без экранизаций и фанатских карт. Карта объединяет оба периода действия (1957–58 и 1984–85), каждая отметка имеет степень уверенности от A (положение прямо задано текстом) до C (правдоподобный вариант); нелокализуемые места вынесены в отдельный список. Это аргументированная реконструкция, а не канон. Метод подробно описан на самом сайте: <https://derryfiles.space/method/>.

Технически это самодостаточное Django/PostgreSQL-приложение: интерактивная SVG-карта, страницы мест с цитатами и источниками, фотогалерея, печатный экспорт (PDF/SVG), английская и русская (`/ru/`) версии. Внешние картографические сервисы и текст романа для работы не нужны.

## Запуск

Нужны Docker Engine с Compose v2 и Python 3. Ориентир для небольшой посещаемости: 2 ядра, 2 ГБ RAM.

```sh
python3 scripts/configure.py --host localhost
docker compose up -d --build
```

Сайт: `http://localhost:8080`. Конфигуратор создаёт `.env` с секретами (повторный вызов их не перезаписывает); миграции, начальная загрузка данных, статика и рельеф выполняются при старте автоматически.

Доступ по IP: `--host <IP> --bind 0.0.0.0`. Домен с HTTPS: привязка остаётся `127.0.0.1`, домен в `--host`, TLS-терминация на внешнем reverse proxy — пример в `docs/deployment.md`.

## Структура

| Путь | Назначение |
|---|---|
| `atlas/` | Единственное Django-приложение |
| `atlas/dataset.py` | Формат данных, проверки, транзакции, версии |
| `atlas/photos.py` | Фотографии: валидация, media, производные размеры |
| `atlas/rendering.py`, `atlas/print_engine.py` | Рельеф, сцена карты, печатные PDF/SVG |
| `atlas/management/commands/` | Команды `atlas` (карта) и `photos` (фотографии) |
| `data/` | Начальный снимок, контрольный baseline, патч русских переводов |
| `docs/` | Архитектура, ER, словарь данных, API, эксплуатация |
| `scripts/` | Конфигурация, обновление, backup/restore, проверка baseline |
| `tests/` | Тесты Django, браузерный тест, приёмочный сценарий Compose |

## Правка карты

Правки вносятся командами `manage.py atlas` с указанием автора и причины — история сохраняется в БД. Пример:

```sh
docker compose exec web python manage.py atlas edit 12 \
  --name 'Derry Public Library' --x -1490 --y -505 \
  --author 'Developer' --reason 'Reviewed placement'
```

Новая версия сцены собирается при первом запросе. Остальные операции (ссылки, описания, степени уверенности, фотографии): `docs/editing.md`. Печатный экспорт: `manage.py atlas render --output /app/var/exports --format all`.

## Данные и резервные копии

Тома: `pgdata` (БД), `media` (фотографии), `artifacts` (воспроизводимый кеш и экспорты).

```sh
sh scripts/backup.sh
sh scripts/update.sh      # после замены исходников новой версией, .env сохраняется
sh scripts/restore.sh backups/derry-YYYYMMDDTHHMMSSZ.dump --yes
```

Дамп содержит данные, источники и всю историю правок; производные картинки пересоздаются. `atlas seed` выполняет начальную загрузку однократно и после первого запуска ничего не меняет.

## Проверки

```sh
# На работающем стеке (отдельная тестовая БД PostgreSQL):
docker compose exec web python manage.py test tests
# Полная приёмка на одноразовых томах, нужен свободный порт 18080:
sh tests/verify_compose.sh
# Неизменность исходной карты:
docker compose exec web python scripts/check_baseline.py
```

Браузерный тест (необязателен): `npm ci && npx playwright install chromium`, затем `DERRY_URL=http://127.0.0.1:8080 npm run test:browser`.
